#### Things I've built

- **[Cirnota](https://cirnota.pt)**: a surgical portfolio for doctors in Portugal, in production. Log surgeries on the day, track residency minimums and export a CV as PDF or Word. React 19, TypeScript, Vite, NestJS, PostgreSQL, with CI running typecheck, lint, tests, a dependency audit and a production boot smoke test.
- **[A Minha Rua](https://a-minha-rua.vercel.app)**: turns any address in Portugal into an isometric pixel-art poster from OpenStreetMap data, with the real sun position, live weather and Stripe checkout. Nuxt 4, three.js, Vitest.
- **[filebridge](https://github.com/nevespvasco/filebridge)**: a cross-platform file-transfer app (Linux, Windows, macOS, Android) that turned a 31-hour manual server migration into a 5-step wizard, with resumable background transfers, filename repair (NFC, mojibake) and SHA-256 verification. Vue 3 + Tauri 2 UI over a Rust engine, with 35 decision records in `docs/adr`.
- **[PushGuard](https://github.com/nevespvasco/pushguard)**: AI code review as a git pre-push hook, with OpenAI, Anthropic or Gemini models and three strictness presets. It fails open, so it never blocks a push. TypeScript, Node 20.
